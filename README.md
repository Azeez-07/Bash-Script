# Bash Scripting Practice

## Overview

This repository contains beginner-level Bash scripting exercises created while learning Linux and shell scripting fundamentals.

## Scripts

### 1. User Information and Voting Eligibility
- Displays welcome messages.
- Accepts the user's name and age.
- Uses variables, arithmetic operations and `if-else` conditions to check voting eligibility.

### 2. Employee Directory and File Creation
- Accepts an employee's name and ID.
- Creates a directory for the employee.
- Creates text files and writes the employee ID to a file.

### 3. Number Guessing Game
- Accepts user input.
- Uses a function, conditional statements and a `for` loop.
- Displays a result based on whether the entered number matches the target number.

## Concepts Practiced

- Bash scripting fundamentals
- Variables and user input
- Conditional statements (`if-else`)
- Arithmetic operations
- Loops (`for`)
- Functions
- File and directory operations

## Prerequisites

- Linux environment or Windows with WSL or Git Bash installed
- Basic command-line knowledge

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Azeez-07/Bash-Script.git
   ```

2. Navigate to the repository:

   ```bash
   cd Bash-Script
   ```

3. Run a script using Bash:

   ```bash
   bash script-name.sh
   ```

   Replace `script-name.sh` with the actual filename of the script you want to execute.

## Learning Objective

The goal of this repository is to strengthen Bash scripting fundamentals through small, practical exercises and build a foundation for Linux administration and DevOps automation.

## Disclaimer

These are learning exercises, not production-ready automation scripts. Input validation and security improvements can be added as the scripts evolve.
